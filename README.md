# research-agents

Phase 0 provides portable research-skill discovery, a portable research-project
initializer, and native harness adapters.

## Install

- [Codex](docs/install/codex.md)
- [Claude Code](docs/install/claude-code.md)
- [OpenCode](docs/install/opencode.md)

The [research-project initializer](skills/initializing-research-project/SKILL.md)
is shared across the supported installations. Follow the installation pages
above to make it available in your preferred coding agent.

See the [compatibility matrix](docs/compatibility.md) for current smoke-test
evidence and support status.
